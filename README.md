# Kick & Goal

Play: https://moosama76.github.io/kick-and-goal/

A desktop keyboard/mouse action-platformer with nine ball puzzles. Choose one loadout before starting.

Controls: A/D or arrows to move, Space to jump, left click to aim/kick, hold R or right click to recall the ball, Q/E for Ball Blink when equipped, L/Escape for the menu, Backspace to restart.

## Hosting

GitHub Pages serves the main branch from the repository root. All runtime assets are local; no build or server is required. Open index.html locally or use the live link.

The Phaser runtime is MIT licensed; its notice is in vendor/PHASER-LICENSE.md. The game artwork and audio are generated by the included game code.
