# Kick & Goal

Play: https://moosama76.github.io/kick-and-goal/

Desktop keyboard/mouse action-platformer with nine ball puzzles. Choose one loadout before starting.

Move: A/D or arrows. Jump: Space. Aim/kick: left click. Recall: hold R or right click. Ball Blink: Q/E when equipped. Menu: L/Escape. Restart: Backspace.

GitHub Pages publishes main from the repository root. All runtime assets are local; no build or application server is required. Phaser is MIT licensed; see vendor/PHASER-LICENSE.md.
